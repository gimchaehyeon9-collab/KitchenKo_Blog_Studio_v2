키친앤코 블로그 스튜디오 2.8.1
==============================

[처음 한 번만]
1) Node.js LTS 설치: https://nodejs.org  (이미 있으면 생략)
2) 크롬 확장 설치
   - 크롬 주소창에 chrome://extensions 입력
   - 오른쪽 위 [개발자 모드] 켜기
   - 예전 "키친앤코 · 네이버 글쓰기 연결" 확장이 있으면 [삭제]
   - [압축해제된 확장 프로그램을 로드합니다] → 이 폴더 안의 chrome-extension 폴더 선택
   - 설치할 때 "디버거" 권한 안내가 나오는데, 네이버 화면에 실제 키보드처럼 입력하기 위해 필요한 권한입니다.

[매번 사용할 때]
1) start.vbs 더블클릭 → 크롬에 스튜디오가 열립니다
   (안 열리면 start.bat 실행 → 오류 내용이 보입니다)
2) ① 현장 정보: 아파트명을 적으면 지역이 자동으로 채워집니다 (네이버 지도 검색)
      같은 이름이 여러 곳이면 목록에서 고르고, 틀리면 직접 고치면 됩니다
      이어서 시공 품목, 컬러 톤, 가구 사양을 입력
3) ② 키워드: [검색량 조회] — 크롬에서 searchad.naver.com 에 로그인하고
      [도구 → 키워드 도구] 화면을 열어 둔 상태에서 누르세요.
      A(아파트명) · B(제목 맨 앞 키워드)가 검색량 기준으로 자동 선택됩니다.
      표의 [A] [B] 버튼으로 직접 바꿀 수 있어요.
4) ③ 사진: 사진과 동영상을 함께 끌어다 놓으면 알아서 나뉩니다 → [2장씩 자동 콜라주]
      - 카드 머리(⠿)를 끌거나 ↑↓ 로 순서 변경
      - 작은 사진을 끌어서 콜라주 안 순서 변경 / 다른 카드로 이동
      - [분리]로 콜라주에서 빼기, 체크 후 [체크한 카드 묶기]로 합치기
      - 사진을 올리면 순서대로 '내용'이 자동으로 정해지고(첫 사진 = 전체 느낌, 마지막 = 수납),
        초안 문단이 바로 써집니다. 마음에 들면 그대로 쓰면 됩니다.
      - 마음에 안 들면 → 카드의 [키워드로 다듬기]를 펼쳐서
        도어 / 디테일 / 수납 / 상판 / 분위기 / 강조할 점 중 사진에 보이는 것을 고르세요.
        고른 키워드는 문단에 꼭 들어가고, 고르지 않은 디테일은 들어가지 않습니다.
      - '내용'을 직접 바꾼 카드는 사진 순서를 바꿔도 그대로 유지됩니다
      - 문단은 직접 고쳐도 되고, 고친 문단은 자동으로 바뀌지 않습니다
      - [문장 다시 섞기]: 직접 고치지 않은 문단을 다른 표현으로 바꿉니다
      - 카드마다 '이 사진에 꼭 넣을 내용' 칸 → 그 내용이 문단에 들어갑니다
      - 카드의 [다시 쓰기]: 그 문단만 다른 문장으로
      - 현장 정보의 '이 글에 꼭 넣을 내용' → 마지막 문단에 들어갑니다

   ★ 사진을 보고 쓰게 하려면 — Claude Code(-p) 자동 작성 (Claude 구독 요금제 · API 요금 없음)
      [처음 한 번만]
      ① 명령 프롬프트(cmd)에서  npm install -g @anthropic-ai/claude-code
      ② 명령 프롬프트에서  claude auth login  → 브라우저에서 Claude 구독 계정으로 로그인
      ③ 스튜디오 오른쪽 'Claude로 사진 보고 쓰기' 칸에 "✓ Claude Code 연결됨"이 뜨면 준비 끝
      [쓸 때]
      - 사장님이 ChatGPT와 다듬은 실제 문장도 사진 종류에 맞게 골라 말투 예시로 함께 보냅니다
      - 사진을 올리고 [Claude로 자동 작성 (사진 보고)] → 1~3분 뒤 제목·문단이 카드마다 들어갑니다
      - 카드의 [Claude로 다시]: 그 문단만 사진을 보고 다시 씁니다
      - 사진은 임시 폴더로 옮겨 Claude Code가 읽게 하고, 끝나면 지웁니다
      - 이 PC에 API 키(ANTHROPIC_API_KEY)가 설정돼 있어도 무시하고 구독 로그인만 씁니다
      - 구독 사용량이 조금씩 차감됩니다 (사진 수에 비례)
      - 안 될 때: 같은 칸 아래 [직접 채팅에 올리기] ZIP 방식도 그대로 쓸 수 있어요

5) ④ 대표사진: 카드의 [대표] 버튼으로 고르고 위치 조정 (1080×1080)
6) 오른쪽에서 제목 고르기 → 미리보기 확인
7) [네이버에 입력하고 임시저장] — 새 글쓰기 창을 자동으로 열어서 입력합니다
   (크롬에 네이버 로그인만 되어 있으면 됩니다)
   '기존 글 서식 그대로'가 켜져 있으면 다대롯데캐슬블루 글과 같은 서식으로 저장됩니다
   (회색 시공정보 · 작은 지도 카드 · 구분선 · 네이버 콜라주 · 가운데 정렬 문의 안내 · 링크 카드 · 동영상)
   * 입력하는 동안 네이버 창을 클릭하거나 스크롤하지 마세요.
   * '발행'은 절대 누르지 않습니다. 임시저장 목록에서 확인 후 직접 발행하세요.
8) 발행할 때 직접 할 것
   - 태그 칸에 [해시태그 복사] 붙여넣기
   - 가운데 정렬 등 글자 서식이 필요하면 조정

[안 될 때]
- 실패하면 오른쪽 위 [설정] → '문제가 생겼을 때' → [진단 정보 복사]를 눌러 채팅에 붙여 보내 주세요
- 확장을 새 버전으로 바꾼 뒤에는 chrome://extensions 에서 키친앤코 확장의 [새로고침 ↻]을 누르세요
- 확장 미설치로 나오면: chrome://extensions 에서 사용 설정 확인 → 스튜디오 탭 새로고침
- 장소/링크/동영상 카드가 실패하면 그 항목만 건너뛰고 계속 진행합니다 (상태창에 표시)
- 동영상이 안 올라가면 오른쪽 위 [설정] → '문제가 생겼을 때' → [동영상 창 구조 보기]를 눌러 주세요.
  네이버 동영상 창을 열어 안의 구조만 읽어 복사합니다 (글은 바뀌지 않음). 그 내용을 채팅에 붙여 주시면 원인을 찾을 수 있어요.
- 그래도 안 올라가면: 임시저장된 글을 네이버에서 열어 [동영상] 버튼으로 직접 올리세요.
  그리고 [진단 정보 복사]를 눌러 채팅에 붙여 주시면 원인을 찾을 수 있어요.
- 사진 업로드나 문단 확인이 실패하면 임시저장을 누르지 않고 멈춥니다.
  편집기에 일부 내용이 남아 있을 수 있으니 새 글을 열고 다시 시도하세요.
- 문장 표현 바꾸기: public/js/phrases.js 파일 하나만 고치면 됩니다.
- 검색광고 API 키·Claude Code 설치 안내·기존 글 서식 가져오기는 오른쪽 위 [설정] 안에 모여 있습니다.
- 검색광고 API 키는 내 PC 사용자 폴더(.kitchenko-studio)에 저장되어 새 버전에서도 그대로 유지됩니다.
- 오른쪽 [제목] / [미리보기] 탭으로 바꿔 볼 수 있습니다.

  · ② 자동 영상: 영상을 직접 올리지 않았으면 [임시등록] 직전에 사진들(각인 포함)로 영상을 만들어 올려요. 사진 1장에 2초, 사진 사이는 부드럽게 넘어가요. 사진이 40장보다 많으면 고르게 골라 써요. 영상 만들기에 실패하면 영상 없이 계속 올리고 로그에 알려 줘요. [영상 빼기]로 일부러 뺀 글은 다시 만들지 않아요. 끄는 곳은 ①과 같아요. 영상 형식은 크롬이 만들 수 있는 것을 써요 (mp4 우선, 안 되면 webm).
  · ③ 해시태그 6~8개: 구·단지(차수 있는 이름 / 없는 이름)·동에 리모델링·인테리어를 붙여 만들어요. 예) 해운대구 재송동 센텀파크1차 → 해운대리모델링, 센텀파크1차리모델링, 센텀파크1차인테리어, 센텀파크리모델링, 재송동리모델링, 센텀파크인테리어, 해운대인테리어, 재송동인테리어. 차수가 없는 단지는 겹치는 태그를 빼고 구·동 인테리어로 채워 6개 이상을 맞춰요. 이미 만들어 둔 글의 태그는 그대로이고, 글 만들기(초안)를 다시 하거나 현장 정보(구·동·아파트명)를 고쳐 저장하면 새 규칙으로 바뀌어요. 태그는 직접 고칠 수 있어요.
  · ④ VPN · 접속 IP (카페 화면 [설정] → [VPN · 접속 IP]): ESvpn처럼 PC 전체에 적용되는 VPN은 먼저 VPN을 연결한 뒤 [접속 IP 확인]을 눌러 보세요. 그 IP로 카페 프로그램의 크롬(로그인 창 · 자동 작업)이 나가요. 로그인할 때와 글을 올릴 때 모두 VPN을 켠 상태로 하세요. (카페 프로그램이 VPN 프로그램의 [연결] 버튼을 대신 누르지는 못해요.) 프록시 주소(예: socks5://127.0.0.1:1080)로 쓰는 VPN이면 [프록시 주소로 연결하는 VPN인 경우]에 적을 수 있어요. 아이디·비밀번호가 필요한 프록시는 지원하지 않아요.
  · 지금까지처럼 [임시등록]까지만 하고 카페 [등록] 버튼은 직접 눌러 주세요.
- 알아 둘 점: 이 환경에서는 진짜 네이버 카페·인스타·VPN에 접속할 수 없어서 아래까지만 확인했어요 — 각인 위치·모양(시험 사진), 영상 만들기(시험 사진 4장 → 8초 mp4), 해시태그 규칙, 카페 설정 화면 동작, 영상 자동 만들기 흐름(만들기 · 재사용 · 끄기 · 직접 올린 영상 보존), 업데이트 복사·백업, 인스타 zip 내려받기, 제목 목록 화면. 실제 카페 글쓰기 화면에 각인 사진·영상이 올라가는 부분과 ESvpn 연결 상태에서의 접속 IP는 써 보시고 알려 주세요.
