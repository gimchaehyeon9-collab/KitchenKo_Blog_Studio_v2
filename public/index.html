어제 글 링크 · 네이버 노출 순위 자동 기록

다음 날이 되면 시트에서 링크·순위가 비어 있는 전날(최근 2주) 글을 찾아, 블로그에서 글 주소를 가져오고 네이버에서 두 키워드의 순위를 조회해 “15 / 2”처럼 적어요. 네이버에 안 보이면 -로 적어요. 이미 적힌 칸은 건드리지 않아요.

순위 조회 방식 (기본: 키 없이 네이버 블로그탭 검색)

기본은 키 없이 네이버 통합검색의 블로그탭에서 상위 20위 안의 순위를 찾아요. (blog-exposure-check 노출 기록 프로그램과 같은 방식)

네이버가 막지 않도록 검색 사이를 2.5초씩 쉬어요. 20위 안에 없으면 -로 적어요. 너무 자주 조회하면 네이버가 잠시 막을 수 있어서 하루 한 번만 자동으로 돌아요.

API 키로 조회하려는 분만 쓰세요. NAVER API HUB: 네이버 클라우드 플랫폼 콘솔 → All Services → Application Services → NAVER API HUB → 신청하기 → Application 등록(사용 API: 검색) → [인증 정보]의 Client ID/Secret. 순위는 블로그 검색(정확도순) 상위 300건 안에서 찾은 값이라 실제 검색 화면과 조금 다를 수 있어요.
